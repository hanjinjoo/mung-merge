# 짧은 게임 효과음

외부 음원 샘플을 사용하지 않고 사인파, 주파수 이동, 짧은 감쇠 포락선으로 만든 효과음입니다. 모두 모노 MP3이며 실행 시 추가 음성 서비스나 생성 도구가 필요하지 않습니다.

| 파일 | 용도 | 기본 개별 볼륨 |
|---|---|---:|
| drop.mp3 | 정상 드롭 | 0.40 |
| collision.mp3 | 강한 일반 충돌 | 0.12 |
| merge.mp3 | 결과 단계2~5 합체 | 0.50 |
| big_merge.mp3 | 결과 단계6~7 합체 | 0.60 |
| final.mp3 | 결과 단계8 생성, 특별 시각 연출 없음 | 0.68 |
| gameover.mp3 | 게임오버 진입1회 | 0.48 |

마스터 볼륨은0.60입니다. 개별 볼륨과 곱해지므로 여러 효과가 겹쳐도 작고 부담 없는 수준을 목표로 합니다. MP3 디코딩 기준 길이는 약0.13~0.52초입니다. BGM은 없습니다.

누락되거나 디코딩에 실패한 파일은 건너뛰며 게임은 계속 진행합니다. 교체할 때 파일명을 유지하면 됩니다. 설정과 재생 제한은 src/systems/AudioSystem.js에서 관리합니다.
