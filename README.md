# 멍수박 · 가나디 최종본 (GitHub Pages용)

하단 최종 가나디 아이콘 확대까지 반영된 실행용 파일입니다. 별도의 설치나 빌드는 필요 없습니다.

1. ZIP을 압축 해제합니다.
2. 안의 index.html, assets 폴더, .nojekyll, README.md를 GitHub 저장소 최상위에 업로드합니다. ZIP 파일 자체나 바깥 폴더를 업로드하지 마세요.
3. 저장소 Settings → Pages → Source에서 Deploy from a branch를 선택합니다.
4. Branch는 업로드한 브랜치(보통 main), 폴더는 /(root)로 선택하고 Save를 누릅니다.
5. 배포가 끝나면 Pages에 표시되는 웹 주소로 접속합니다.

이미 Pages가 같은 브랜치의 /(root)로 설정되어 있다면 파일 업로드만 하면 갱신됩니다.
GitHub 파일 미리보기나 PC에서 index.html을 더블클릭하는 방식은 실행 방법이 아닙니다.
최고 점수는 기기·브라우저·사이트 주소별로 저장됩니다.
